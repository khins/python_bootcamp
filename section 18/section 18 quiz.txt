1. What does a loop over menu directly yield for menu = {"tea": 3, "cake": 5}?
   A. 3, then 5
   B. "tea", then "cake"
   C. ("tea", 3), then ("cake", 5)

   A. for key, value in menu.keys():
   B. for key, value in menu.values():
   C. for key, value in menu:
   D. for key, value in menu.items():

       keys = menu.keys()

       menu["coffee"] = 4
       print(len(keys), len(saved))

   B. 1 1
   C. 2 2

4. What is sorted({"Zoe": 2, "Alex": 9, "Sam": 5})?
   A. [2, 5, 9]
   B. ["Zoe", "Sam", "Alex"]
   C. ["Alex", "Sam", "Zoe"]
   D. {"Alex": 9, "Sam": 5, "Zoe": 2}

5. Which expression sorts dictionary items by their VALUES in ascending order?
   A. sorted(scores.items(), key=lambda pair: pair[0])
   B. sorted(scores.items(), key=lambda pair: pair[1])
   C. scores.sort()
   D. sorted(scores.keys())

                  {"title": "Tarkus", "year": 1971}]
